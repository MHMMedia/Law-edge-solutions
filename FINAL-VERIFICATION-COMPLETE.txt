DEPLOYMENT INSTRUCTIONS:

1. Copy static_site/ directory to your VPS:
   scp -r static_site/ user@your-vps.com:/var/www/lawedgesolutions/

2. Configure web server (nginx example):
   server {
       listen 80;
       server_name www.lawedgesolutions.com;
       root /var/www/lawedgesolutions/static_site;
       index index.html;
   }

3. Point domain DNS to VPS IP address

4. Set up SSL/HTTPS with LetsEncrypt:
   certbot --nginx -d www.lawedgesolutions.com

5. Test the live site in browser:
   https://www.lawedgesolutions.com/
